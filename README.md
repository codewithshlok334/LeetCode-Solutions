## Browse my solutions

Synced solutions appear in the problem folders below this README. Each folder contains the submitted code and any problem notes generated by the sync tool.

This repository starts empty of solutions. Problem folders are added when a submission is successfully synced; the repository does not represent my complete LeetCode history until earlier solutions have been imported.

## How submissions arrive here

The intended sync tool is [LeetHub-3.0](https://github.com/raphaelheinz/LeetHub-3.0). Once the browser extension is authorized and linked to this repository, it can push accepted submissions from LeetCode automatically.

- Submit from the browser profile where the extension is installed and connected.
- Wait for the sync indicator to finish before changing the editor or leaving the page.
- Older accepted submissions can be opened and synced with the extension's manual sync button.
- Each successful upload becomes a GitHub commit, making it easy to revisit an approach.

See [connection and verification steps](SETUP.md) for the one-time setup.
