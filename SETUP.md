# Connect LeetCode to this repository

## Target accounts

| Setting | Value |
| --- | --- |
| LeetCode account | `hereshlok` |
| GitHub owner | `codewithshlok334` |
| Repository | `LeetCode-Solutions` |
| Repository URL | https://github.com/codewithshlok334/LeetCode-Solutions |

## One-time browser connection

1. In the browser where you solve problems, install [LeetHub-3.0 from its Chrome Web Store listing](https://chromewebstore.google.com/detail/leethub-30/kdkgpjpenaeoodajljkflmlnkoihkmda).
2. Open the extension and choose **Authorize with GitHub**. Confirm that GitHub shows `codewithshlok334`, review the requested access, and authorize it if acceptable.
3. Select **Get Started**, then the option to link an **existing repository**. Use `LeetCode-Solutions` in the `codewithshlok334` account.
4. Open LeetCode in that same browser profile and sign in as `hereshlok`.

## Verify the connection

Open one of your existing accepted submissions and use LeetHub's manual sync button. Check this repository for a new problem folder containing your submitted solution. This verifies the connection without submitting a new answer just for setup.

After a new submission is **Accepted**, wait for the extension's sync indicator to finish (the project advises about four seconds) before changing the code or leaving the editor. Confirm the matching GitHub commit on your first new solve.

## Practical limits

- The extension must be enabled and connected in the browser profile used for LeetCode. Mobile apps and other browser profiles do not automatically share this setup.
- Existing solutions are not guaranteed to import just by linking the repository. Open an earlier accepted submission and use manual sync when needed.
- If GitHub authorization expires or is revoked, reconnect the extension. Already committed solutions remain in GitHub.
- This sync works through the browser extension and does not require the Codex app to stay open.

Source: [LeetHub-3.0 setup and synchronization documentation](https://github.com/raphaelheinz/LeetHub-3.0).
